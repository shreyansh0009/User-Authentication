# User Authentication System 🔑


A robust and secure user authentication system built using EJS and JavaScript. This project provides a foundation for managing user accounts, including registration, login, and secure password handling.


## Quick Start 🚀

Get started quickly with these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shreyansh0009/User-Authentication.git
   ```

2. **Install dependencies:**
   ```bash
   cd User-Authentication
   ```
   ```bash
   npm install nodemon -g
   ```
   ```bash
   npm install express
   ```
   ```bash
   npm install ejs
   ```
   ```bash
   npm install mongoose
   ```
   ```bash
   npm install jsonwebtoken
   ```
   ```bash
   npm install cookie-parser
   ```
   ```bash
   npm install bcrypt
   ```

3. **Run the application:**
   ```bash
   nodemon app.js
   ```
